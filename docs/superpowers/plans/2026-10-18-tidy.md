# Tidy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On the horizon wall, one quiet affordance under the zone bands, "Tidy 4 notes", proposes where the jotted notes go (Today / This week / Later); every note to move shows its destination on its card with the dashed edge and the waiting dot; Enter or Keep moves them all with a 180 ms staggered transform, and one Undo puts the batch back (0005-wallybot-inline.md §3.5, §6.4).

**Architecture:** A new approval record, `assistantTidies`, holds one batch: a list of moves (note, base revision, from, to, reason, source) with one apply and one undo operation id per move, decided as a whole through the command layer's `move_note` (`HORIZON`), so every move is attributed, audited and replayable. The server builds the batch from a date rule for dated notes (no model) and one structured model call for the undated notes in Today (the same boundary, reservation and settlement as a capture turn). On the web a new controller, `useTidy`, owns the one batch per board, derives a per-note mark the cards draw, applies a keep optimistically so the cards can travel, and keeps the 30 s undo window; a slim bar under the bands is the affordance and the batch's control; `WallView` animates the moved cards from their old place to their new one.

**Tech Stack:** Fastify + Zod + firebase-admin; Vercel AI SDK behind `apps/api/src/lib/assistant/model/`; React 19 + TanStack Query 5 + Web Animations API (as `settleCard` already uses). No new dependency.

**Spec:** `docs/rfcs/0005-wallybot-inline.md` §3.5, §4, §6 (decisions 1, 3, 4, 5), §7; `docs/rfcs/0003-wally-agent.md` §3.2 (writes wait for a yes; the approval is the server's record; stale changes are refused; writes are attributed) and §3.3 (`move_note` is already on the surface: no new operation); `docs/BRAND.md` "## AI" rules 3–6, "Marigold has four jobs", "Shape, depth and motion". Slices 2 and 3 (`docs/superpowers/plans/2026-10-17-capture-suggest.md`, `2026-10-17-capture-review.md`) are the record of the record-and-chain pattern this reuses.

## Context

The RFC says two things about Tidy that do not agree: §3.5 and §6.4 give it "the same countdown and undo" as a capture, while §6.1 and WALLY_AGENT §3.2 say nothing that moves an existing note is applied without the person's yes. Decisions, each with its reason and its cost if wrong:

- **R1. Tidy waits for the person's yes.** Choosing "Tidy 4 notes" asks for a proposal; the cards show where each note would go; nothing moves until Enter on a marked card or Keep in the bar. The dot waits (as it does under "always ask me"); no countdown runs. §6.1 is the safety rule the owner approved for moves, and the approval of a specific, visible change is what WALLY_AGENT §3.2 means by a yes; §6.4's "same countdown and undo" is read as the same look and the same one-step undo. Cost if wrong: one Enter per tidy.
- **R2. The horizon wall only, open notes the person may move.** A candidate is an open note the caller may edit (a VIEW member: their own private notes) that is either dated with a horizon that disagrees with the date rule (R3), or undated and in Today, the zone every new note lands in. A note with a pending Wallybot change is left out (one pending change per note). The priority wall and the free canvas have no Tidy. Cost if wrong: a filter to widen.
- **R3. The date rule, and one call for the rest.** Due today or earlier → Today; due by the Sunday of the current week → This week; later → Later. Dated notes move by this rule with no model call. Undated candidates (at most 30, newest first) go to the model in one structured call with today's date; it may send a note to This week or Later with a confidence of at least 0.6 and a short reason; anything else stays. No candidates, or nothing worth moving, means no record. Cost if wrong: two constants and a prompt line.
- **R4. The affordance is a slim bar under the bands**, always present on the horizon wall while the board's assistant is on, so nothing reflows when it fills: "Tidy 4 notes" (N counts the candidates on the board now) while idle; "Sorting…" with the dot while asking; "3 notes move · Keep · Discard" while pending; "3 notes moved · Undo" for 30 s after a keep; "Nothing to tidy" for 4 s when the server found nothing worth moving. After a run the affordance stays hidden until the set of candidates changes (ids and revisions, client memory only). Cost if wrong: a 28 px strip.
- **R5. One record per batch, decided as a whole, moved note by note.** `assistantTidies/{id}` holds the moves with one apply and one undo operation id each; a keep claims the record and runs `move_note` `HORIZON` for each kept note on its own `baseRevision`; a note that changed since the proposal, is gone, or may no longer be moved is skipped and the rest moves (a batch is not all-or-nothing: the person asked for the wall to be tidied, not for a transaction); a repeat resumes under the same ids. Undo moves each applied note back on the revision the keep produced, skipping any note changed since, and records `UNDONE`. Cost if wrong: a skipped note is one drag.
- **R6. On the card:** the dashed edge, the waiting dot, and a destination line in the card's own type, "→ This week", with the reason as its tooltip (the due date for a dated note, the model's words otherwise) and an × that takes the note out of the batch; the last × out discards the batch. No source mark beyond that (slice 3, R5). Cost if wrong: a line to restyle.
- **R7. Keys:** Enter on a marked card or Keep in the bar keeps the batch; Esc on a marked card or Discard in the bar discards it; after a keep, Undo sits where the dot was on every moved card and in the bar; Esc on a moved card undoes; `⌘Z` undoes the batch when no kept Wallybot change is more recent. Cost if wrong: a key to remap.
- **R8. Motion:** a keep patches the cache first, so the cards move at once; each moved card travels from its old place to its new one in 180 ms, 40 ms apart, transform only, nothing under reduced motion; the server's answer follows; a note the server skipped is put back without motion and nothing is said (BRAND rule 5). A refusal or a failure puts every card back the same way. Cost if wrong: a flicker on a refused keep.
- **R9. Nothing survives a reload.** A pending tidy is for the moment; a new tidy request discards the previous pending one on the server; records expire after 7 days (TTL, like suggestions). Cost if wrong: one more click after a reload.
- **R10. The persisted horizon values stay `HEUTE`, `DIESE_WOCHE`, `SPAETER`** (ADR-0014's rename is a separate release on `feat/english-values`); every new identifier is English.

```ts
import type { NoteHorizon } from '../enums.js';

/**
 * The Sunday that ends the week `today` is in, as a YYYY-MM-DD string. A calendar date's
 * weekday is the same in every zone, so the day is read in UTC.
 */
export function endOfWeek(today: string): string {
  const date = new Date(`${today}T00:00:00Z`);
  date.setUTCDate(date.getUTCDate() + ((7 - date.getUTCDay()) % 7));
  return date.toISOString().slice(0, 10);
}

/**
 * Where a dated note belongs on the horizon wall (0005-wallybot-inline.md §3.5, plan R3): due
 * today or earlier is Today, due by the Sunday of this week is This week, anything after
 * is Later. Both strings are YYYY-MM-DD, so the string order is the calendar order.
 */
export function horizonForDueDate(dueDate: string, today: string): NoteHorizon {
  if (dueDate <= today) return 'HEUTE';
  if (dueDate <= endOfWeek(today)) return 'DIESE_WOCHE';
  return 'SPAETER';
}
```

```ts
import { z } from 'zod';
import { noteHorizonSchema } from '../enums.js';

/** Undated notes one tidy call may read; the newest ones go first (plan R3). */
export const TIDY_MAX_UNDATED = 30;
/** Moves one batch may hold: every dated candidate plus what the model proposes. */
export const TIDY_MAX_MOVES = 60;
/** Below this the model's placing of an undated note is dropped. */
export const TIDY_MIN_CONFIDENCE = 0.6;

const firestoreId = z.string().regex(/^[A-Za-z0-9_-]{1,128}$/, 'Invalid id');

/** POST /whiteboards/:id/assistant/tidies: the browser's date and zone, nothing else. */
export const tidyRequestSchema = z
  .object({
    timeZone: z.string().min(1).max(64),
    today: z.string().date(),
  })
  .strict();
export type TidyRequest = z.infer<typeof tidyRequestSchema>;

/** A move came from the date rule, or from the model reading the note's words (R3). */
export const tidyMoveSourceSchema = z.enum(['date', 'words']);
export type TidyMoveSource = z.infer<typeof tidyMoveSourceSchema>;

export const tidyMoveSchema = z.object({
  noteId: z.string(),
  /** The note revision the move was computed against; a keep skips the note past it (R5). */
  baseRevision: z.number().int().nonnegative(),
  from: noteHorizonSchema,
  to: noteHorizonSchema,
  /** The model's words for a move by words; null for a move by date (the card says the date). */
  reason: z.string().max(120).nullable(),
  source: tidyMoveSourceSchema,
});
export type TidyMove = z.infer<typeof tidyMoveSchema>;

export const tidyStatusSchema = z.enum(['PENDING', 'KEPT', 'UNDONE', 'DISCARDED']);
export type TidyStatus = z.infer<typeof tidyStatusSchema>;

export const tidyDtoSchema = z.object({
  id: z.string(),
  boardId: z.string(),
  status: tidyStatusSchema,
  moves: z.array(tidyMoveSchema).max(TIDY_MAX_MOVES),
  /** After a keep: the notes that moved and those the keep left where they were (R5). */
  kept: z
    .object({
      noteIds: z.array(z.string()),
      skipped: z.array(z.string()),
    })
    .nullable(),
  createdAt: z.string().datetime(),
});
export type TidyDto = z.infer<typeof tidyDtoSchema>;

/** `tidy` is null when there is nothing worth moving: no record is written then. */
export const tidyResponseSchema = z.object({ tidy: tidyDtoSchema.nullable() });
export type TidyResponse = z.infer<typeof tidyResponseSchema>;

export const tidyDecisionSourceSchema = z.enum(['enter', 'esc', 'click', 'shortcut', 'remove']);
export const tidyDecisionSchema = z
  .object({
    decision: z.enum(['keep', 'discard', 'undo']),
    /** For `keep`: the notes still in the batch; omitted means every proposed move. */
    noteIds: z.array(firestoreId).max(TIDY_MAX_MOVES).optional(),
    source: tidyDecisionSourceSchema,
  })
  .strict();
export type TidyDecision = z.infer<typeof tidyDecisionSchema>;
export const tidyDecisionResponseSchema = z.object({ tidy: tidyDtoSchema });
```

```ts
      .flatMap((parsed) => (parsed.success ? [parsed.data] : []))

      const checked = modelTidySchema.safeParse(value);
      return checked.success
        ? { success: true, value: checked.data }
        : { success: false, error: checked.error };
    },
  },

/**
 * One structured call (0005-wallybot-inline.md §4), shaped like a capture's: announced and settled
 * through the lease, the library's retries off, thinking room added to the allowance so the
 * ledger reserves what can be billed. A reply that does not validate is "nothing to move".
 */
export function createTidyRunner(
  model: LanguageModel,
  options: Partial<SuggestionCallSettings> = {},
): TidyRunner {
  const thinkingTokens = options.thinkingTokens ?? 0;
  return async (input: TidyInput): Promise<TidyOutput> => {
    const maxOutputTokens = input.maxOutputTokens + thinkingTokens;
    const lease = await input.onAttempt({ stepNumber: 0, messageCount: 1, maxOutputTokens });
    try {
      const result = await generateText({
        model,
        instructions: input.instructions,
        prompt: input.prompt,
        output: Output.object({ schema: replySchema }),
        maxRetries: 0,
        maxOutputTokens,
        ...(options.providerOptions ? { providerOptions: options.providerOptions } : {}),
        abortSignal: input.abortSignal,
      });
      const usage = toUsage(result.usage);
      if (usage) await lease.settle(usage);
      return { moves: result.output, usage, finishReason: result.finishReason };
    } catch (error) {
      if (NoObjectGeneratedError.isInstance(error)) {
        const usage = error.usage ? toUsage(error.usage) : null;
        if (usage) await lease.settle(usage);
        return { moves: null, usage, finishReason: error.finishReason ?? 'other' };
      }
      throw error;
    }
  };
}

let schemaJson: Promise<string> | null = null;

export function tidySchemaJson(): Promise<string> {
  schemaJson ??= Promise.resolve(zodSchema(modelTidyWireSchema).jsonSchema).then((schema) =>
    JSON.stringify(schema),
  );
  return schemaJson;
}

    | 'FIREBASE_CLIENT_EMAIL'
    | 'FIREBASE_PRIVATE_KEY'
```

```ts
import {
  horizonForDueDate,
  TIDY_MAX_UNDATED,
  TIDY_MIN_CONFIDENCE,
  type EffectiveRole,
  type NoteDto,
  type NoteHorizon,
  type TidyMoveSource,
} from '@wally/shared';
import type { ModelTidy } from './model/index.js';

export type TidyNote = Pick<
  NoteDto,
  | 'id'
  | 'title'
  | 'description'
  | 'status'
  | 'horizon'
  | 'dueDate'
  | 'revision'
  | 'visibility'
  | 'createdBy'
  | 'createdAt'
>;

export interface PlannedMove {
  noteId: string;
  baseRevision: number;
  from: NoteHorizon;
  to: NoteHorizon;
  reason: string | null;
  source: TidyMoveSource;
}

/**
 * Who may move which note, as the command layer will decide it (`rolesFor`): an owner or an
 * editor moves any note they can see, a viewer only their own private notes (plan R2, R10).
 * Proposing a move the keep would refuse is a move the person cannot make.
 */
export function mayMoveFor(role: EffectiveRole, actorId: string): (note: TidyNote) => boolean {
  if (role !== 'VIEW') return () => true;
  return (note) => note.visibility === 'PRIVATE' && note.createdBy?.id === actorId;
}

/**
 * What Tidy looks at (0005-wallybot-inline.md §3.5, plan R2, R3): among the open notes the person
 * may move, the dated ones whose zone disagrees with their date move by the rule, and the
 * undated ones still in Today, newest first and at most `TIDY_MAX_UNDATED`, go to the model.
 */
export function tidyCandidates(
  notes: TidyNote[],
  today: string,
  mayMove: (note: TidyNote) => boolean,
): { dated: PlannedMove[]; undated: TidyNote[] } {
  const open = notes.filter((note) => note.status === 'OPEN' && mayMove(note));
  const dated: PlannedMove[] = [];
  for (const note of open) {
    if (!note.dueDate) continue;
    const to = horizonForDueDate(note.dueDate, today);
    if (to !== note.horizon)
      dated.push({
        noteId: note.id,
        baseRevision: note.revision,
        from: note.horizon,
        to,
        reason: null,
        source: 'date',
      });
  }
  const undated = open
    .filter((note) => !note.dueDate && note.horizon === 'HEUTE')
    .sort((a, b) => (a.createdAt < b.createdAt ? 1 : a.createdAt > b.createdAt ? -1 : 0))
    .slice(0, TIDY_MAX_UNDATED);
  return { dated, undated };
}

/**
 * The model's moves as the batch may hold them: a listed undated note, once, away from Today,
 * confident enough; the reason travels to the card (R3).
 */
export function acceptModelMoves(moves: ModelTidy['moves'], undated: TidyNote[]): PlannedMove[] {
  const byId = new Map(undated.map((note) => [note.id, note]));
  const seen = new Set<string>();
  const out: PlannedMove[] = [];
  for (const move of moves) {
    const note = byId.get(move.noteId);
    if (!note || seen.has(move.noteId) || move.confidence < TIDY_MIN_CONFIDENCE) continue;
    if (move.horizon === note.horizon) continue;
    seen.add(move.noteId);
    out.push({
      noteId: note.id,
      baseRevision: note.revision,
      from: note.horizon,
      to: move.horizon,
      reason: move.reason,
      source: 'words',
    });
  }
  return out;
}
```

```ts
/**
 * Claims the record for one decision in a transaction, as a suggestion's `claim` does: two
 * tabs deciding at once agree on one outcome, the second replays the first's.
 */
export async function claimTidy(
  db: Firestore,
  actor: Actor,
  boardId: string,
  id: string,
  from: AssistantTidyDoc['status'],
  to: AssistantTidyDoc['status'],
  decision: { source: string; noteIds: string[] },
  now: Date,
): Promise<{ doc: WithId<AssistantTidyDoc>; claimed: boolean }> {
  const ref = assistantTidiesCol(db, actor.id).doc(id);
  return db.runTransaction(async (tx) => {
    const current = withId(await tx.get(ref));
    if (!current || current.boardId !== boardId) throw notFound();
    if (current.status === to) return { doc: current, claimed: false };
    if (current.status !== from) throw settled();
    const stamp = Timestamp.fromDate(now);
    const next: WithId<AssistantTidyDoc> = {
      ...current,
      status: to,
      ...(to === 'UNDONE'
        ? { undone: { source: decision.source, at: stamp } }
        : { decision: { ...decision, at: stamp } }),
      updatedAt: stamp,
    };
    tx.set(ref, stripId(next));
    return { doc: next, claimed: true };
  });
}

/** Every pending tidy of this caller on this board is discarded: one proposal at a time (R9). */
async function discardPending(db: Firestore, actor: Actor, boardId: string, now: Date) {
  const pending = docsWithId(
    await assistantTidiesCol(db, actor.id)
      .where('boardId', '==', boardId)
      .where('status', '==', 'PENDING')
      .get(),
  );
  if (pending.length === 0) return;
  const stamp = Timestamp.fromDate(now);
  const col = assistantTidiesCol(db, actor.id);
  await db.runTransaction(async (tx) => {
    for (const snap of await tx.getAll(...pending.map((doc) => col.doc(doc.id))))
      if (snap.data()?.status === 'PENDING')
        tx.update(snap.ref, { status: 'DISCARDED', updatedAt: stamp });
  });
}

  actor: Actor,
  boardId: string,
): Promise<Set<string>> {
  const docs = await assistantSuggestionsCol(db, actor.id)
    .where('boardId', '==', boardId)
    .where('status', '==', 'PENDING')
    .get();
  return new Set(docs.docs.map((snap) => snap.data().noteId));
}

/**
 * One Tidy (0005-wallybot-inline.md §3.5, plan R3): read the open notes, move the dated ones by the
 * rule, ask the model about the undated ones in Today (reserve, call, settle), and store the
 * batch only when there is something to move. Throws BudgetError and AppError only; the
 * provider's own error becomes 502 without its wording.
 */
export async function proposeTidy(
  deps: TidyDeps,
  ctx: SuggestionContext,
  request: TidyRequest,
): Promise<TidyDto | null> {
  const clock = () => deps.now?.() ?? new Date();
  const { db, env } = deps;
  const { actor, board } = ctx;
  const now = clock();
  await discardPending(db, actor, board.id, now);

  const notes = await listNotes(db, actor, board.id, { status: 'OPEN' });
  const busy = await notesWithPendingSuggestion(db, actor, board.id);
  const { dated, undated } = tidyCandidates(
    notes.filter((note) => !busy.has(note.id)),
    request.today,
    mayMoveFor(ctx.role, actor.id),
  );
  if (dated.length === 0 && undated.length === 0) return null;

  let byWords: PlannedMove[] = [];
  let model: string | null = null;
  let usage: AssistantTidyDoc['usage'] = null;
  if (undated.length > 0) {
    const instructions = buildTidyInstructions({
      today: request.today,
      timeZone: request.timeZone,
      language: ctx.language,
    });
    const prompt = buildTidyPrompt(
      undated.map((note) => ({ id: note.id, title: note.title, text: note.description })),
    );
    const schema = await tidySchemaJson();
    model = env.ASSISTANT_MODEL;
    const price = priceFor(model);
    const caps = {
      dailyTokens: env.ASSISTANT_DAILY_CAP_TOKENS,
      monthlyMicroUsd: env.ASSISTANT_MONTHLY_CAP_MICRO_USD,
    };
    const controller = new AbortController();
    const deadline = setTimeout(() => controller.abort(), deps.deadlineMs ?? TIDY_DEADLINE_MS);
    const startedAt = Date.now();
    let output;
    try {
      output = await deps.runner({
        instructions,
        prompt,
        maxOutputTokens: TIDY_MAX_OUTPUT_TOKENS,
        abortSignal: controller.signal,
        onAttempt: async (info) => {
          const reservation = await reserveAttempt(db, {
            userId: actor.id,
            now: clock(),
            estimate: {
              inputTokens: estimateTokens([instructions, prompt, schema]) + 16,
              outputTokens: info.maxOutputTokens,
            },
            price,
            caps,
          });
          return {
            settle: (used) =>
              settleAttempt(
                db,
                actor.id,
                reservation.attemptId,
                { inputTokens: used.inputTokens, outputTokens: used.outputTokens },
                clock(),
              ),
          };
        },
      });
    } catch (error) {
      if (error instanceof AppError) throw error;
      deps.logger?.warn({
        type: 'assistant.provider_error',
        boardId: board.id,
        name: (error as { name?: unknown } | null)?.name,
        status: (error as { statusCode?: unknown } | null)?.statusCode,
      });
      throw new AppError(502, 'ASSISTANT_PROVIDER_ERROR', 'The model provider failed');
    } finally {
      clearTimeout(deadline);
    }
    deps.logger?.info({
      type: 'assistant.tidy',
      boardId: board.id,
      undated: undated.length,
      proposed: output.moves?.moves.length ?? 0,
      usage: output.usage,
      ms: Date.now() - startedAt,
    });
    usage = {
      inputTokens: output.usage?.inputTokens ?? 0,
      outputTokens: output.usage?.outputTokens ?? 0,
    };
    if (output.moves) byWords = acceptModelMoves(output.moves.moves, undated);
  }

  const moves = [...dated, ...byWords];
  if (moves.length === 0) return null;
  const stamp = Timestamp.fromDate(now);
  const doc: AssistantTidyDoc = {
    boardId: board.id,
    status: 'PENDING',
    moves: moves.map((move) => ({
      ...move,
      operationIds: { apply: randomUUID(), undo: randomUUID() },
    })),
    decision: null,
    undone: null,
    applied: null,
    model,
    usage,
    createdAt: stamp,
    updatedAt: stamp,
    expiresAt: Timestamp.fromMillis(now.getTime() + SUGGESTION_RETENTION_DAYS * 86_400_000),
  };
  const ref = assistantTidiesCol(db, actor.id).doc();
  await ref.create(doc);
  return toTidyDto({ ...doc, id: ref.id });
}
```

```ts
import { runOperation, type OperationContext } from './run.js';

function operationContext(
  deps: SuggestionDeps,
  ctx: SuggestionContext,
  id: string,
): OperationContext {
  return {
    db: deps.db,
    actor: ctx.actor,
    boardId: ctx.board.id,
    assistantEnabled: true,
    // The tidy is the approval record; a tidy has no conversation (as a suggestion, plan R2 of slice 2).
    provenance: { via: 'assistant', conversationId: id, approvalId: id },
    logger: deps.logger,
  };
}

/** A refusal that a retry under the same id cannot change (stale, gone, forbidden, invalid). */
const isFinal = (error: unknown): error is AppError =>
  error instanceof AppError && error.statusCode < 500;

type TidyMoveDoc = AssistantTidyDoc['moves'][number];

/**
 * Moves the notes, each under its own operation id on the revision given, skipping the ones
 * the command layer refuses for good (changed since, gone, not the caller's to move) and
 * throwing on anything else, so the caller can resume later under the same ids. Returns what
 * moved, with the revision each move produced, and what was skipped (plan R5).
 */
async function moveEach(
  opCtx: OperationContext,
  moves: {
    move: TidyMoveDoc;
    to: TidyMoveDoc['to'];
    expectedRevision: number;
    operationId: string;
  }[],
): Promise<{ moved: { noteId: string; revision: number }[]; skipped: string[] }> {
  const moved: { noteId: string; revision: number }[] = [];
  const skipped: string[] = [];
  for (const { move, to, expectedRevision, operationId } of moves) {
    try {
      const result = await runOperation(opCtx, {
        name: 'move_note',
        input: {
          boardId: opCtx.boardId,
          noteId: move.noteId,
          expectedRevision,
          input: { mode: 'HORIZON', horizon: to },
        },
        operationId,
      });
      moved.push({ noteId: move.noteId, revision: result.revision ?? expectedRevision });
    } catch (error) {
      if (!isFinal(error)) throw error;
      skipped.push(move.noteId);
    }
  }
  return { moved, skipped };
}

/**
 * Finishes a claimed keep: every keep of a KEPT record with nothing applied comes here (the
 * claiming tab, a second tab, a repeat after a cut-short keep) and runs the same moves under
 * the record's apply ids, so each note moves once and each move leaves one audit row.
 */
async function completeKeep(
  deps: SuggestionDeps,
  ctx: SuggestionContext,
  doc: WithId<AssistantTidyDoc>,
): Promise<WithId<AssistantTidyDoc>> {
  if (doc.applied) return doc;
  const chosen = new Set(doc.decision?.noteIds ?? []);
  const { moved, skipped } = await moveEach(
    operationContext(deps, ctx, doc.id),
    doc.moves
      .filter((move) => chosen.has(move.noteId))
      .map((move) => ({
        move,
        to: move.to,
        expectedRevision: move.baseRevision,
        operationId: move.operationIds.apply,
      })),
  );
  const ref = assistantTidiesCol(deps.db, ctx.actor.id).doc(doc.id);
  const now = deps.now?.() ?? new Date();
  return deps.db.runTransaction(async (tx) => {
    const current = withId(await tx.get(ref));
    if (!current) throw notFound();
    if (current.status !== 'KEPT' || current.applied) return current;
    const next: WithId<AssistantTidyDoc> = {
      ...current,
      applied: { moves: moved, skipped },
      updatedAt: Timestamp.fromDate(now),
    };
    tx.set(ref, stripId(next));
    return next;
  });
}

/**
 * Keep, discard or undo the batch (0005-wallybot-inline.md §3.5, plan R5, R7). A keep moves the
 * chosen notes through the command layer under the record's own operation ids; a note changed
 * since the proposal is skipped and the rest moves. An undo moves each applied note back on
 * the revision its move produced, under the undo ids, skipping a note changed since.
 */
export async function decideTidy(
  deps: SuggestionDeps,
  ctx: SuggestionContext,
  tidyId: string,
  decision: TidyDecision,
): Promise<TidyDto> {
  const { db } = deps;
  const { actor, board } = ctx;
  const now = deps.now?.() ?? new Date();

  if (decision.decision === 'discard') {
    const { doc } = await claimTidy(
      db,
      actor,
      board.id,
      tidyId,
      'PENDING',
      'DISCARDED',
      { source: decision.source, noteIds: [] },
      now,
    );
    return toTidyDto(doc);
  }

  if (decision.decision === 'keep') {
    const current = await loadTidy(db, actor, board.id, tidyId);
    if (current.status === 'KEPT') return toTidyDto(await completeKeep(deps, ctx, current));
    // Each proposed note once, in the record's order; a note the record never proposed is ignored.
    const requested = decision.noteIds ? new Set(decision.noteIds) : null;
    const noteIds = current.moves
      .map((m) => m.noteId)
      .filter((id) => !requested || requested.has(id));
    if (noteIds.length === 0) {
      const { doc } = await claimTidy(
        db,
        actor,
        board.id,
        tidyId,
        'PENDING',
        'DISCARDED',
        { source: decision.source, noteIds: [] },
        now,
      );
      return toTidyDto(doc);
    }
    const { doc } = await claimTidy(
      db,
      actor,
      board.id,
      tidyId,
      'PENDING',
      'KEPT',
      { source: decision.source, noteIds },
      now,
    );
    return toTidyDto(await completeKeep(deps, ctx, doc));
  }

  // undo
  let current = await loadTidy(db, actor, board.id, tidyId);
  if (current.status === 'UNDONE') return toTidyDto(current);
  if (current.status !== 'KEPT') throw settled();
  current = await completeKeep(deps, ctx, current);
  const { applied } = current;
  if (current.status !== 'KEPT' || !applied) throw settled();
  const byId = new Map(current.moves.map((m) => [m.noteId, m]));
  await moveEach(
    operationContext(deps, ctx, current.id),
    [...applied.moves].reverse().flatMap(({ noteId, revision }) => {
      const move = byId.get(noteId);
      return move
        ? [{ move, to: move.from, expectedRevision: revision, operationId: move.operationIds.undo }]
        : [];
    }),
  );
  const { doc } = await claimTidy(
    db,
    actor,
    board.id,
    tidyId,
    'KEPT',
    'UNDONE',
    { source: decision.source, noteIds: applied.moves.map((m) => m.noteId) },
    now,
  );
  return toTidyDto(doc);
}
```

```ts
import { horizonForDueDate, type NoteDto } from '@wally/shared';

/**
 * The notes "Tidy N notes" counts (0005-wallybot-inline.md §3.5, plan R2, R4), the same rule the
 * server applies: an open note the person may move, dated and in a zone its date disagrees
 * with, or undated and still in Today. A note with a pending Wallybot change is left out.
 * In board order, so the count is stable from one render to the next.
 */
export function tidyCandidateIds(
  notes: readonly NoteDto[],
  today: string,
  canMove: (note: NoteDto) => boolean,
  busy: ReadonlySet<string>,
): string[] {
  const out: string[] = [];
  for (const note of notes) {
    if (note.status !== 'OPEN' || busy.has(note.id) || !canMove(note)) continue;
    if (
      note.dueDate
        ? horizonForDueDate(note.dueDate, today) !== note.horizon
        : note.horizon === 'HEUTE'
    )
      out.push(note.id);
  }
  return out;
}

/** What the affordance remembers after a run: the candidates and their revisions, order-free (R4). */
export function candidateSignature(
  notes: readonly Pick<NoteDto, 'id' | 'revision'>[],
  ids: readonly string[],
): string {
  const revisions = new Map(notes.map((n) => [n.id, n.revision]));
  return [...ids]
    .sort()
    .map((id) => `${id}@${revisions.get(id) ?? 0}`)
    .join(',');
}
```

```ts
import { useQueryClient } from '@tanstack/react-query';
import type { NoteDto, NoteHorizon, TidyDto, TidyMoveSource } from '@wally/shared';
import { assistantApi } from '@/lib/resources';
import {
  cancelNoteCaches,
  patchNoteCaches,
  restoreNoteCaches,
  settleNoteCaches,
  snapshotNoteCaches,
  type NoteCacheSnapshot,
} from '../hooks/mutations/shared';
import { useQueryKeys } from '../hooks/queryKeys';
import { UNDO_WINDOW_MS } from '../Suggestions/useSuggestions';
import { candidateSignature, tidyCandidateIds } from './tidyCandidates';

/** How long "Nothing to tidy" stays in the bar (plan R4). */
export const EMPTY_NOTICE_MS = 4000;

export type TidyPhase = 'idle' | 'asking' | 'pending' | 'kept' | 'empty';
export type TidySource = 'enter' | 'esc' | 'click' | 'shortcut' | 'remove';

/** What a card draws for a note in the batch (plan R6). */
export interface TidyMark {
  to: NoteHorizon;
  from: NoteHorizon;
  reason: string | null;
  source: TidyMoveSource;
  phase: 'pending' | 'kept';
}

export interface TidyController {
  phase: TidyPhase;
  /** Candidates on the board now; 0 hides the affordance (R4). */
  count: number;
  /** Moves still in the batch (pending), or moved (kept). */
  moving: number;
  /** The batch's notes while it is pending or kept: what the wall measures to animate (R8). */
  trackedIds: readonly string[];
  markFor: (noteId: string) => TidyMark | undefined;
  tidy: () => void;
  keep: (source: 'enter' | 'click') => void;
  discard: (source: 'esc' | 'click') => void;
  undo: (source: 'esc' | 'click' | 'shortcut') => void;
  /** ⌘Z: undoes the kept batch while its window is open; false when there is none. */
  undoLast: () => boolean;
  /** The card's ×: takes the note out of the batch; the last one out discards (R6). */
  remove: (noteId: string) => void;
}

/** Today in the browser's calendar, as the API expects it. */
function localToday(): string {
  const d = new Date();
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;
}

interface Batch {
  tidy: TidyDto;
  /** Notes taken out with the × while pending. */
  removed: Set<string>;
  /** After a keep: the notes that moved, in the record's order. */
  moved: string[];
}

/**
 * The board's Tidy (0005-wallybot-inline.md §3.5, plan R1–R9): one batch at a time. The count is
 * the client's own (the same rule as the server's); the proposal is the server's record; a
 * keep moves the notes in the cache at once so the cards travel (R8) and tells the server,
 * which may skip a note changed since (R5); the undo window is the client's 30 s, as a
 * suggestion's. Nothing is said when the server refuses: the cards go back (BRAND rule 5).
 */
export function useTidy(
  boardId: string,
  enabled: boolean,
  notes: readonly NoteDto[],
  canMove: (note: NoteDto) => boolean,
  busy: ReadonlySet<string>,
): TidyController {
  const queryClient = useQueryClient();
  const keys = useQueryKeys();
  const [phase, setPhase] = useState<TidyPhase>('idle');
  const [batch, setBatch] = useState<Batch | null>(null);
  /** The candidates as they were when the last run ended; the affordance waits for a change (R4). */
  const [lastRun, setLastRun] = useState<string | null>(null);
  const timer = useRef<ReturnType<typeof setTimeout> | null>(null);
  const snapshots = useRef(new Map<string, NoteCacheSnapshot>());
  /** The request on its way, so a stale answer changes nothing. */
  const token = useRef<symbol | null>(null);
  const latestNotes = useRef(notes);
  latestNotes.current = notes;
  const latestBatch = useRef(batch);
  latestBatch.current = batch;
  const latestPhase = useRef(phase);
  latestPhase.current = phase;

  const candidates = useMemo(
    () => (enabled ? tidyCandidateIds(notes, localToday(), canMove, busy) : []),
    [busy, canMove, enabled, notes],
  );
  const signature = candidateSignature(notes, candidates);
  const count = phase === 'idle' && signature !== lastRun ? candidates.length : 0;

  const clearTimer = () => {
    if (timer.current) clearTimeout(timer.current);
    timer.current = null;
  };
  /** Back to idle; the affordance remembers what the board looked like at that moment (R4). */
  const rest = useCallback(() => {
    clearTimer();
    token.current = null;
    snapshots.current.clear();
    setBatch(null);
    setPhase('idle');
    const ids = tidyCandidateIds(latestNotes.current, localToday(), canMove, busy);
    setLastRun(candidateSignature(latestNotes.current, ids));
  }, [busy, canMove]);

  /** The moves still in the batch, in the record's order. */
  const activeMoves = (b: Batch) =>
    b.tidy.moves.filter(
      (m) => !b.removed.has(m.noteId) && (b.moved.length === 0 || b.moved.includes(m.noteId)),
    );

  const patchAll = useCallback(
    (moves: { noteId: string; horizon: NoteHorizon }[]) => {
      for (const { noteId, horizon } of moves) {
        cancelNoteCaches(queryClient, keys, boardId, noteId);
        if (!snapshots.current.has(noteId))
          snapshots.current.set(noteId, snapshotNoteCaches(queryClient, keys, boardId, noteId));
        patchNoteCaches(queryClient, keys, boardId, noteId, { horizon });
      }
    },
    [boardId, keys, queryClient],
  );
  const restoreAll = useCallback(
    (noteIds: string[]) => {
      for (const noteId of noteIds) {
        const snapshot = snapshots.current.get(noteId);
        if (snapshot) restoreNoteCaches(queryClient, keys, boardId, noteId, snapshot);
        snapshots.current.delete(noteId);
        settleNoteCaches(queryClient, keys, boardId, noteId);
      }
    },
    [boardId, keys, queryClient],
  );

  const tidy = useCallback(() => {
    if (!enabled || latestPhase.current !== 'idle') return;
    const mine = Symbol('tidy');
    token.current = mine;
    setPhase('asking');
    void assistantApi
      .tidy(boardId, {
        timeZone: Intl.DateTimeFormat().resolvedOptions().timeZone,
        today: localToday(),
      })
      .then(({ tidy: proposed }) => {
        if (token.current !== mine) return;
        token.current = null;
        if (!proposed || proposed.moves.length === 0) {
          setPhase('empty');
          clearTimer();
          timer.current = setTimeout(rest, EMPTY_NOTICE_MS);
          return;
        }
        setBatch({ tidy: proposed, removed: new Set(), moved: [] });
        setPhase('pending');
      })
      .catch(() => {
        if (token.current === mine) rest();
      });
  }, [boardId, enabled, rest]);

  const keep = useCallback<TidyController['keep']>(
    (source) => {
      const b = latestBatch.current;
      if (!b || latestPhase.current !== 'pending') return;
      const moves = activeMoves(b);
      if (moves.length === 0) return;
      const noteIds = moves.map((m) => m.noteId);
      // The cache first, so the cards travel now; the server's answer follows (R8).
      patchAll(moves.map((m) => ({ noteId: m.noteId, horizon: m.to })));
      setBatch({ ...b, moved: noteIds });
      setPhase('kept');
      const mine = Symbol('keep');
      token.current = mine;
      void assistantApi
        .decideTidy(boardId, b.tidy.id, { decision: 'keep', noteIds, source })
        .then(({ tidy: decided }) => {
          if (token.current !== mine) return;
          token.current = null;
          if (decided.status !== 'KEPT' || !decided.kept) {
            restoreAll(noteIds);
            rest();
            return;
          }
          // A note the server skipped goes back where it was, without motion (R5, R8).
          const skipped = decided.kept.skipped;
          if (skipped.length) restoreAll(skipped);
          for (const id of decided.kept.noteIds) settleNoteCaches(queryClient, keys, boardId, id);
          setBatch((current) =>
            current ? { ...current, tidy: decided, moved: decided.kept!.noteIds } : current,
          );
          clearTimer();
          timer.current = setTimeout(rest, UNDO_WINDOW_MS);
        })
        .catch(() => {
          if (token.current !== mine) return;
          restoreAll(noteIds);
          rest();
        });
    },
    [boardId, keys, patchAll, queryClient, rest, restoreAll],
  );

  const discard = useCallback<TidyController['discard']>(
    (source) => {
      const b = latestBatch.current;
      if (!b || latestPhase.current !== 'pending') return;
      void assistantApi
        .decideTidy(boardId, b.tidy.id, { decision: 'discard', source })
        .catch(() => {});
      rest();
    },
    [boardId, rest],
  );

  const undo = useCallback<TidyController['undo']>(
    (source) => {
      const b = latestBatch.current;
      if (!b || latestPhase.current !== 'kept') return;
      const back = b.tidy.moves.filter((m) => b.moved.includes(m.noteId));
      patchAll(back.map((m) => ({ noteId: m.noteId, horizon: m.from })));
      const noteIds = back.map((m) => m.noteId);
      const mine = Symbol('undo');
      token.current = mine;
      setBatch(null);
      setPhase('idle');
      clearTimer();
      void assistantApi
        .decideTidy(boardId, b.tidy.id, { decision: 'undo', source })
        .then(() => {
          for (const id of noteIds) settleNoteCaches(queryClient, keys, boardId, id);
        })
        .catch(() => {
          // The server kept the moves: the cards go back to where the keep put them.
          if (token.current === mine)
            patchAll(back.map((m) => ({ noteId: m.noteId, horizon: m.to })));
          for (const id of noteIds) settleNoteCaches(queryClient, keys, boardId, id);
        })
        .finally(() => {
          if (token.current === mine) rest();
        });
    },
    [boardId, keys, patchAll, queryClient, rest],
  );

  const undoLast = useCallback(() => {
    if (latestPhase.current !== 'kept' || !latestBatch.current) return false;
    undo('shortcut');
    return true;
  }, [undo]);

  const remove = useCallback<TidyController['remove']>(
    (noteId) => {
      const b = latestBatch.current;
      if (!b || latestPhase.current !== 'pending' || b.removed.has(noteId)) return;
      const removed = new Set(b.removed).add(noteId);
      const left = b.tidy.moves.filter((m) => !removed.has(m.noteId));
      if (left.length === 0) {
        discard('click');
        void assistantApi; // the discard above carries source 'click'; see the note below
        return;
      }
      setBatch({ ...b, removed });
    },
    [discard],
  );

  // A note edited while the batch is pending leaves it: a keep would skip it anyway (R5).
  useEffect(() => {
    const b = latestBatch.current;
    if (!b || phase !== 'pending') return;
    const revisions = new Map(notes.map((n) => [n.id, n.revision]));
    const stale = b.tidy.moves.filter(
      (m) => !b.removed.has(m.noteId) && (revisions.get(m.noteId) ?? -1) !== m.baseRevision,
    );
    if (stale.length === 0) return;
    const removed = new Set(b.removed);
    for (const m of stale) removed.add(m.noteId);
    if (b.tidy.moves.every((m) => removed.has(m.noteId))) discard('click');
    else setBatch({ ...b, removed });
  }, [discard, notes, phase]);

  // Leaving the board: the timer goes; a pending record is discarded by the next request (R9).
  useEffect(() => () => clearTimer(), []);

  const markFor = useCallback<TidyController['markFor']>(
    (noteId) => {
      const b = latestBatch.current;
      if (!b || (phase !== 'pending' && phase !== 'kept')) return undefined;
      const move = activeMoves(b).find((m) => m.noteId === noteId);
      if (!move) return undefined;
      return {
        to: move.to,
        from: move.from,
        reason: move.reason,
        source: move.source,
        phase: phase === 'kept' ? 'kept' : 'pending',
      };
    },
    [batch, phase], // eslint-disable-line react-hooks/exhaustive-deps -- `batch` is read through the ref; it is a dep so the cards re-render on every change
  );
  const trackedIds = useMemo(
    () =>
      batch && (phase === 'pending' || phase === 'kept')
        ? activeMoves(batch).map((m) => m.noteId)
        : [],
    [batch, phase],
  );

  return useMemo(
    () => ({
      phase,
      count,
      moving: trackedIds.length,
      trackedIds,
      markFor,
      tidy,
      keep,
      discard,
      undo,
      undoLast,
      remove,
    }),
    [count, discard, keep, markFor, phase, remove, tidy, trackedIds, undo, undoLast],
  );
}
```

```ts
import type { KeyboardEvent } from 'react';
import type { TidyMark } from './useTidy';

/** What a card needs to draw and report a note's part in the batch (plan R6, R7). */
export interface TidyProps {
  mark: TidyMark;
  /** Enter on the card keeps the whole batch. */
  onKeep: (source: 'enter') => void;
  /** Esc on a card still pending discards the whole batch. */
  onDiscard: () => void;
  /** Esc on a moved card, or its Undo, puts the whole batch back. */
  onUndo: (source: 'esc' | 'click') => void;
  /** The ×: this note stays where it is; the last one out discards. */
  onRemove: () => void;
}

/** Enter keeps, Esc discards (pending) or undoes (kept). True when the key was taken. */
export function tidyKeys(event: KeyboardEvent, tidy: TidyProps | undefined): boolean {
  if (!tidy || event.nativeEvent.isComposing) return false;
  if (event.key === 'Enter' && tidy.mark.phase === 'pending') {
    event.preventDefault();
    event.stopPropagation();
    tidy.onKeep('enter');
    return true;
  }
  if (event.key === 'Escape') {
    event.preventDefault();
    event.stopPropagation();
    if (tidy.mark.phase === 'pending') tidy.onDiscard();
    else tidy.onUndo('esc');
    return true;
  }
  return false;
}
```

`apps/web/src/features/board/Tidy/useFlip.ts`:

```ts
import { useLayoutEffect, useRef } from 'react';

/**
 * Moves the tracked cards from where they were to where they are, after every render that
 * changes their place (0005-wallybot-inline.md §3.5: "a 180 ms transform each, staggered"). A card
 * that changes zone is re-parented and remounted, so no CSS transition can carry it; the Web
 * Animations API on the new element can, the way `settleCard` lands a drop. Transform only,
 * nothing under reduced motion (BRAND.md). Measures only the ids given, before and after.
 */
export function useFlip(
  ids: readonly string[],
  { durationMs = 180, staggerMs = 40 }: { durationMs?: number; staggerMs?: number } = {},
) {
  const before = useRef(new Map<string, DOMRect>());
  useLayoutEffect(() => {
    const reduce = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
    const after = new Map<string, DOMRect>();
    let index = 0;
    for (const id of ids) {
      const el = document.querySelector<HTMLElement>(`[data-note-id="${CSS.escape(id)}"]`);
      if (!el) continue;
      const rect = el.getBoundingClientRect();
      after.set(id, rect);
      const was = before.current.get(id);
      if (!was || reduce) continue;
      const dx = was.left - rect.left;
      const dy = was.top - rect.top;
      if (Math.abs(dx) < 2 && Math.abs(dy) < 2) continue;
      el.animate([{ transform: `translate(${dx}px, ${dy}px)` }, { transform: 'translate(0, 0)' }], {
        duration: durationMs,
        delay: staggerMs * index++,
        easing: 'cubic-bezier(0.2, 0.7, 0.2, 1)',
        fill: 'backwards',
      });
    }
    before.current = after;
  });
}
```

(jsdom has no `CSS.escape` in some versions; `settleCard` already uses it on this code base, so it is available in the test setup. If the test setup lacks `el.animate`, the test defines it, as above.)
